## Mandatory Guardrails for Vibe Coding
- Follow feature-based folder organization: features/, common/, routes/.
- Keep UI, business logic, and data layers separate.
- Use PascalCase for component and file names.
- Prefer functional components with hooks.
- Keep each React component focused on a single responsibility.
- Use linting and formatting consistently; do not introduce style violations.
- Add tests for meaningful UI behavior before shipping new features.
- Maintain accessibility basics: semantic HTML, keyboard-friendly interactions, and clear labels.
- Avoid storing sensitive data in client-side state.
- Keep the app structure extensible for future growth.
